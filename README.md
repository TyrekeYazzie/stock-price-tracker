# Stock Price Tracker

A Python application that retrieves historical stock market data using the Alpha Vantage API and visualizes stock prices with Plotly.

## Features

* Retrieve historical stock price data.
* View stock data across supported time periods.
* Visualize price trends with charts.
* Handle API requests and potential errors.

## Technologies Used

* Python
* Alpha Vantage API
* Requests
* Plotly

## Getting Started

### 1. Install Python

Install Python 3 if it is not already installed.

### 2. Clone the repository

```bash
git clone https://github.com/TyrekeYazzie/stock-price-tracker.git
cd stock-price-tracker
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure your API key

Get an API key from [Alpha Vantage](https://www.alphavantage.co/support/#api-key).

Configure the application to use your API key. Keep your key private and never commit it to GitHub.

### 5. Run the application

```bash
python stock_tracker.py
```
